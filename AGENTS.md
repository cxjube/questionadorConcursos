## Scope and architecture

Use the existing checkout. Cloud tasks are already isolated; do not create Git worktrees unless requested by the user.

The app is static HTML/CSS/classic JavaScript in `docs/`. No runtime framework, external service, account, CDN or analytics. Canonical JSON lives in `data/catalog.json`; Python validates it and generates `docs/data/catalog.js`. Never hand-edit that generated artifact.

The current delivery continues the user-approved roadmap with personalized practice, fifteen reviewed batches (339 released items; a disjoint 154+170 C/E reserve), 339 referenced didactic comments, discipline/topic performance and daily evolution (7/30/all calendar days). Study sessions, local resume/history, errors/unanswered review and backup export/import remain supported. Practice supports target syllabus block/origin/year/format filters, optional persisted deadlines and two explicitly custom scoring presets. A separate exam mode now allocates 90+90 distinct C/E with a versioned official-rule snapshot, fixed 300-minute deadline and independently evaluated 18/27/54 minima. Do not apply these minima to custom practice; see documentation/exam-release.md. Broader roadmap items remain separate deliveries; do not add gamification or extensive unreviewed imports. Workbench files remain outside the published artifact.

uv run python -m tools review-batch
