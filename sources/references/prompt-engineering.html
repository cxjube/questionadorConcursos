Técnicas de engenharia de prompt

Neste artigo

Essas técnicas não são recomendadas para modelos de raciocínio, como modelos gpt-5 e série o.

A construção de prompt pode ser difícil. Na prática, o prompt atua para ajudar o modelo a concluir a tarefa desejada, mas é mais uma arte do que uma ciência, muitas vezes exigindo experiência e intuição para criar um prompt bem-sucedido. O objetivo deste artigo é ajudar você a começar esse processo de aprendizagem. Este artigo tenta capturar conceitos e padrões gerais que se aplicam a todos os modelos de GPT. No entanto, é importante entender que cada modelo se comporta de forma diferente, portanto, os aprendizados podem não se aplicar igualmente a todos os modelos.

Básico

Essa seção aborda os conceitos e os elementos básicos dos prompts GPT.

Os prompts de texto são como os usuários interagem com modelos de GPT. Assim como acontece com todos os modelos de linguagem generativos, os modelos GPT tentam produzir a próxima série de palavras mais propensas a seguir a partir do texto anterior. É como se estivessemos dizendo qual é a primeira coisa que vem à sua mente quando eu digo <prompt>? Os exemplos abaixo demonstram esse comportamento. Dadas as primeiras palavras de conteúdo famoso, o modelo é capaz de continuar o texto com precisão.

Prompt Conclusão
Há 87 anos, nossos nossos ancestrais estabeleceram neste continente uma nova nação, concebida sob os ideais de liberdade, e dedicada ao princípio de que todos os homens são criados iguais. […]
"Chame-me Ismael." "Alguns anos atrás — não importa há quanto tempo precisamente — tendo pouco ou nenhum dinheiro no meu bolso, e nada em particular para me interessar em terra firme, pensei em navegar um pouco e ver a parte aquática do mundo."

À medida que você desenvolve prompts mais complexos, é útil ter esse comportamento fundamental em mente. Independentemente do prompt fornecido, o modelo está simplesmente respondendo com o que ele determina ser mais provável (dado seus dados de treinamento e objetivos de treinamento). Se você fizer uma pergunta em seu prompt, o modelo não está seguindo um caminho de código "Q&A" separado, mas parece responder à pergunta porque uma resposta é o tipo mais provável de resposta para a pergunta fornecida como entrada.

Componentes de solicitação

Quando você usa a API de Compleções e não há diferenciação entre as diferentes partes do prompt, ainda pode ser útil, para fins de aprendizado e discussão, identificar os componentes subjacentes do prompt. Com a API de Conclusão de Chat, seções distintas do prompt são enviadas à API como uma matriz de dicionários com funções associadas: sistema, usuário e assistente. Essa orientação se concentra de forma mais geral em como pensar sobre a construção de prompts em vez de fornecer diretrizes prescritivas específicas a uma API em vez de outra.

Também é importante entender que, embora possa haver outras maneiras válidas de analisar os prompts, o objetivo desse detalhamento é oferecer uma forma relativamente simples de pensar sobre a criação de prompts. Com a API de Conclusão, todos os componentes são opcionais, mas pelo menos um deve estar presente e a maioria dos prompts inclui mais de um componente. Também pode haver alguma área cinzenta entre os componentes. A ordem apresentada na seção a seguir corresponde aproximadamente à frequência com que cada componente é usado, da maioria para o mínimo.

Conteúdo principal

O conteúdo primário refere-se ao texto que o modelo processa ou transforma. Normalmente, você usa o conteúdo primário com instruções. Um exemplo simples é a tradução de idioma. No exemplo a seguir, o texto em inglês é o conteúdo primário e "Traduzir para francês:" é uma instrução.

Prompt Conclusão
Pode me dizer como chegar ao museu?
Traduzir para francês:		 Pouvez-vous s'il vous plaît me dire comment aller au musée?

O conteúdo primário também pode ser muito mais longo. No exemplo a seguir, o conteúdo primário é a seção de introdução da entrada da Wikipédia sobre complexidade temporal, que tem quase 300 palavras. Esse conteúdo é abreviado na tabela para facilitar a exibição.

Resumir o texto anterior em algumas frases:		 A complexidade do tempo é uma medida de quanto tempo um algoritmo leva para ser executado. Normalmente, ele é expresso como uma função do tamanho da entrada. A medida mais comum é a complexidade de tempo na pior das hipóteses, que é a quantidade máxima de tempo necessária para entradas de um determinado tamanho.

Exemplos

As solicitações bem-sucedidas geralmente dependem da prática de aprendizado de "única tentativa" ou "algumas tentativas". Essa prática envolve incluir um ou mais exemplos do comportamento desejado do modelo, normalmente incluindo pares de entrada e saída. Essa abordagem não é aprendizado no sentido de que o modelo seja alterado permanentemente, mas sim de que os exemplos condicionam melhor o modelo a responder da maneira desejada somente na inferência atual. Às vezes, o uso de solicitações sem exemplos é chamado de aprendizado "sem tentativa". Observe que, com a API de Preenchimento de Chat, você normalmente adiciona alguns exemplos de aprendizado são à matriz messages na forma de interações de usuário e assistente de exemplo após a mensagem inicial do sistema.

Conteúdo de Apoio

Conteúdo de apoio são informações que o modelo pode usar para influenciar a saída. Ele difere do conteúdo primário, pois não é o destino principal da tarefa, mas normalmente é usado junto com o conteúdo primário. Exemplos comuns incluem informações contextuais, como a data atual, o nome do usuário, as preferências do usuário e assim por diante. O exemplo a seguir usa o conteúdo de suporte para ajudar a organizar um conjunto de workshops planejados para o usuário. Sem o conteúdo de suporte (tópicos importantes), o modelo simplesmente lista os workshops (truncados para exibição). Quando informado dos meus tópicos importantes, o modelo agrupa com precisão as reuniões.

Orientação específica para o cenário

As técnicas desta seção ensinam estratégias para aumentar a precisão e a fundamentação das respostas que você gera usando um modelo de linguagem de grande porte (LLM). No entanto, é importante lembrar que, mesmo quando você usa a engenharia de prompt efetivamente, ainda precisa validar as respostas geradas pelos modelos. Só porque um prompt cuidadosamente elaborado funcionou bem para um cenário específico não significa necessariamente que ele generalizará de forma mais ampla para certos casos de uso. Entender as limitações das LLMs é tão importante quanto entender como aproveitar seus pontos fortes.

Este guia não se aprofunda na mecânica por trás da estrutura de mensagem para Conclusões de Chat. Se você não estiver familiarizado com a interação com modelos de Conclusões de Chat programaticamente, recomendamos ler nosso guia de instruções sobre a API de Conclusão de Chat primeiro.

Nota

Todos os exemplos nesta seção do guia foram testados em um modelo base de GPT-4 em inglês. Algumas técnicas podem produzir resultados diferentes com modelos mais recentes, como gpt-4.1, e gpt-4.5. Se você estiver lendo uma versão localizada deste artigo em outro idioma, essas respostas representarão uma tradução localizada dos resultados em inglês. Para saber mais sobre possíveis limitações, dependendo da linguagem que você está usando para solicitar um modelo, consulte nossa nota de transparência de IA responsável.

Aprendizado com poucas tentativas

Uma maneira comum de adaptar modelos de linguagem a novas tarefas é usar o aprendizado com poucas chances. No few-shot learning, um conjunto de exemplos de treinamento é fornecido como parte do prompt para dar contexto adicional ao modelo.

Ao usar a API de Conclusões de Chat, uma série de mensagens entre o usuário e o assistente (escritas no novo formato de prompt) pode servir como exemplos para o few-shot learning. Esses exemplos podem ser usados para preparar o modelo para responder de uma determinada maneira, emular comportamentos específicos e inicializar respostas para perguntas comuns.

Mensagem do sistema Exemplos de few-shot learning
O Assistente é um chatbot inteligente projetado para ajudar os usuários a responder suas perguntas relacionadas a impostos.
Instruções
– Responda apenas a perguntas relacionadas a impostos.
- Se você não tiver certeza de uma resposta, poderá dizer "não sei" ou "não tenho certeza" e recomendar que os usuários acessem o site da Receita Federal para obter mais informações.		 Usuário - "Quando preciso declarar meu imposto de renda?"
Assistente - "Em 2023, você precisará declarar seus impostos até o dia 18 de abril. A data cai após o prazo habitual de 15 de abril porque 15 de abril cai em um sábado em 2023. Para obter mais informações, consulte https://www.irs.gov/filing/individuals/when-to-file "

Usuário - "Como posso verificar o status da minha restituição de imposto de renda?"
Assistente - "Você pode verificar o status da sua devolução de impostos visitando https://www.irs.gov/refunds "

Comece com instruções claras

As informações da sequência são exibidas no prompt. Isso ocorre porque os modelos de estilo GPT são criados de uma certa maneira que define como processam a entrada. Nossa pesquisa sugere que dizer ao modelo a tarefa que você deseja que ele faça no início do prompt, antes de compartilhar informações contextuais ou exemplos adicionais, pode ajudar a produzir saídas de maior qualidade.

Nota

Embora seguir essa técnica ainda seja geralmente recomendado, ao contrário das versões anteriores do modelo (GPT-3 e anteriores), nossos testes mostraram que a resposta do modelo com os modelos ChatGPT e GPT-4 era a mesma, independentemente de a técnica ser utilizada. Neste exemplo, vemos que adicionar a declaração "Várias fontes… erupção" no início ou no final do prompt não causou nenhuma alteração na resposta do modelo final.

Mensagem do sistema Usuário Assistente
Você é um assistente de IA que ajuda as pessoas a encontrar informações. Sua tarefa é verificar se a instrução "Várias fontes mencionam uma chance de outra grande erupção" é suportada por uma citação específica do seguinte conjunto de snippets.

Repita as instruções no final

Os modelos podem ser suscetíveis ao desvio de relevância, o que nesse contexto significa que as informações no final do prompt podem ter influência mais significativa sobre a saída do que as informações no início do prompt. Portanto, vale a pena experimentar repetir as instruções no final do prompt e avaliar o impacto na resposta gerada.

Prime a saída

Isso se refere à inclusão de algumas palavras ou frases no final do prompt para obter uma resposta de modelo que siga o formulário desejado. Por exemplo, usar uma indicação como “Here’s a bulleted list of key points:\n- ” pode ajudar a garantir que a saída seja formatada como uma lista de tópicos.

Mensagem do sistema Usuário Assistente
Você é um assistente de IA que ajuda as pessoas a encontrar informações. Responda com o mínimo de palavras possível. John Smith é casado com Lucy Smith. Eles têm cinco filhos, e ele trabalha como engenheiro de software no Microsoft. Quais consultas de pesquisa devo fazer para verificar isso? ## Uma consulta de pesquisa possível é: John Smith é casado com Lucy Smith, tem cinco filhos, e é engenheiro de software na Microsoft.

No prompt acima, o texto Uma consulta de pesquisa possível é: aprimora o modelo para produzir uma única saída. Sem essa indicação, o modelo produz várias consultas de pesquisa como saída.

Adicionar sintaxe clara

Use uma sintaxe clara para o comando a fim de comunicar a intenção e tornar mais fácil a interpretação dos resultados.

No exemplo a seguir, separadores (--- neste caso) foram adicionados entre diferentes fontes de informações ou etapas. Isso permite o uso de --- como uma condição de parada para geração. Além disso, títulos de seção ou variáveis especiais são apresentados em letras maiúsculas para diferenciá-los.

Mensagem do sistema Usuário Assistente
Você é um assistente de IA que ajuda as pessoas a encontrar informações. Você lerá um parágrafo e emitirá consultas a um mecanismo de pesquisa para verificar os fatos. Além disso, explique as consultas.
---
PARÁGRAFO
John Smith é casado com Lucy Smith. Eles têm cinco filhos, e ele trabalha como engenheiro de software no Microsoft. Quais consultas de pesquisa devo fazer para verificar isso?
---
CONSULTAS		 1. "John Smith Microsoft" - Para verificar se John Smith está realmente empregado em Microsoft.
2. "John Smith Lucy Smith" - Para verificar se John Smith é casado com Lucy Smith.
3. "Filhos de John Smith" - Para verificar se John Smith tem cinco filhos.

Se você não tiver certeza de qual sintaxe usar, considere usar Markdown ou XML. Os modelos foram treinados em uma grande quantidade de conteúdo da Web em XML e Markdown, o que pode fornecer melhores resultados.

Divida a tarefa em partes

Os LLMs (modelos de linguagem grandes) geralmente têm um desempenho melhor se a tarefa for dividida em etapas menores. Por exemplo, no prompt de consulta de pesquisa mencionada anteriormente, o prompt pode ser reestruturado para que o modelo primeiro seja instruído a extrair fatos relevantes e, em seguida, instruído a gerar consultas de pesquisa que possam ser usadas para verificar esses fatos.

Mensagem do sistema Usuário Assistente
Você é um assistente de IA que ajuda as pessoas a encontrar informações. Você lerá um parágrafo e emitirá consultas a um mecanismo de pesquisa para verificar os fatos.
---
PARÁGRAFO
John Smith é casado com Lucy Smith. Eles têm cinco filhos, e ele trabalha como engenheiro de software no Microsoft. Quais consultas de pesquisa devo fazer para verificar isso?
---
Agora você extrairá declarações factuais e emitirá consultas para verificá-las. Ao emitir uma consulta, use a função SEARCH("query")

REIVINDICAÇÕES FACTUAIS		 1. John Smith é casado com Lucy Smith
2. Eles têm cinco filhos
3. Ele trabalha como engenheiro de software no Microsoft

CONSULTAS
SEARCH("John Smith casou-se com Lucy Smith")
SEARCH("Tamanho da família John Smith")
SEARCH("John Smith Microsoft engenheiro de software")

Observe o uso da sintaxe clara para diferenciar as seções e preparar a saída. Neste exemplo simples, dividir a tarefa de uma para duas etapas não é muito dramático, mas ao tentar fazer isso para um texto maior com muitas declarações factuais, dividir a tarefa pode fazer uma diferença significativa.

Uso de funcionalidades

Às vezes, podemos fazer com que o modelo use uma funcionalidade em vez de depender de seus próprios parâmetros para obter informações e respostas. A pesquisa, por exemplo, pode ser um recurso para ajudar a mitigar respostas inventadas e obter informações atualizadas.

Uma maneira simples de usar uma acessibilidade é interromper a geração depois que as chamadas de acessibilidade forem geradas pelo modelo e colar os resultados de volta no prompt. Veja abaixo um exemplo de como pode ser a chamada de acompanhamento após as chamadas SEARCH acima. Observe como colamos os resultados da pesquisa no prompt e substituímos as chamadas SEARCH anteriores.

Você é um assistente de IA que ajuda as pessoas a encontrar informações. Você lerá um parágrafo, extrairá declarações factuais e, em seguida, usará os resultados do mecanismo de pesquisa para verificar os fatos

Criação de prompt de cadeia de pensamento

Importante

Essa técnica só é aplicável a modelos de não raciocínio. Tentativas de extrair o raciocínio do modelo por métodos diferentes do parâmetro de resumo de raciocínio não são suportadas, podem violar a Política de Uso Aceitável e resultar em limitação ou suspensão do serviço quando detectadas.

Essa é uma variação na técnica de dividir a tarefa. Em vez de dividir uma tarefa em etapas menores, nessa abordagem, a resposta do modelo é instruida a prosseguir passo a passo e apresentar todas as etapas envolvidas. Isso reduz a possibilidade de imprecisão dos resultados e facilita a avaliação da resposta do modelo.

Mensagem do sistema Usuário Assistente
Você é um assistente de IA que ajuda as pessoas a encontrar informações. Quem foi o atleta individual mais condecorado (medalhas máximas) nos Jogos Olímpicos que foram realizados em Sydney? Siga uma abordagem passo a passo em sua resposta, cite fontes e dê raciocínio antes de compartilhar a resposta final no formato abaixo: ANSWER é: <name> Etapa 1: Determinar o ano dos Jogos Olímpicos de Sydney. Os Jogos Olímpicos de Sydney foram realizados no ano 2000.

Etapa 2: Encontre uma lista de atletas individuais que ganharam várias medalhas nos Jogos Olímpicos de Sydney de 2000.

De acordo com o site oficial dos Jogos Olímpicos, havia vários atletas individuais que ganharam várias medalhas nos Jogos Olímpicos de Sydney de 2000. Alguns dos nomes notáveis incluem:

• Inge de Bruijn (Holanda) - 3 ouros, 1 prata, 0 bronze

Etapa 3: Determinar o atleta com mais medalhas. Depois de revisar a lista de atletas individuais que ganharam várias medalhas nos Jogos Olímpicos de Sydney de 2000, podemos ver que o atleta com mais medalhas é Ian Thorpe, da Austrália, que ganhou um total de 5 medalhas (3 ouros e 2 pratas).

Portanto, a RESPOSTA é: Ian Thorpe.

Especificando a estrutura de saída

Usar seu prompt para especificar a estrutura da saída pode ter um efeito significativo sobre a natureza e a qualidade dos resultados. Às vezes, as entradas de mensagem do sistema como "apenas escrever fatos verdadeiros" ou "não fabricar informações" podem não ser mitigações adequadas. Em vez disso, solicitar que a resposta do modelo inclua citações também pode ajudar a resultar em uma redução da prevalência de respostas incorretas.

Se você instruir o modelo a citar o material de origem quando ele faz instruções, essas instruções são muito mais propensas a serem fundamentadas. Solicitar citações faz com que o modelo faça dois erros sempre que gerar uma resposta: o primeiro erro é a resposta fabricada e o segundo é a citação incorreta. Observe que quanto mais próxima a citação estiver do texto compatível, menor será a distância à frente que o modelo precisa para prever a citação, o que sugere que as citações embutidas são melhores mitigações para geração de conteúdo falso do que citações no final do conteúdo.

Da mesma forma, se você pedir ao modelo para extrair instruções factuais de um parágrafo, ele poderá extrair instruções compostas como 'X está fazendo Y AND Z' (o que pode ser mais difícil de verificar). Isso pode ser evitado especificando uma estrutura de saída, como (entity1, relationship, entity2).

Este exemplo mostra o uso de citações e a orientação da resposta do modelo para se ajustar a uma estrutura definida.

Parâmetros de temperatura e Top_p

Alterar o parâmetro de temperatura altera a saída do modelo. O parâmetro de temperatura pode ser definido entre 0 e 2. Um valor mais alto, 0,7 por exemplo, torna a saída mais aleatória e produz respostas mais divergentes, enquanto um valor menor, como 0.2 torna os resultados mais focados e concretos. Uma história fictícia poderia ser gerada usando uma temperatura mais alta. Enquanto para gerar um documento legal é recomendado usar uma temperatura significativamente mais baixa. Top_probability é outro parâmetro e é semelhante à Temperatura, pois também controla a aleatoriedade da resposta do modelo, mas o faz de uma maneira diferente. A recomendação geral é alterar um desses dois parâmetros de cada vez, não ambos.

Fornecer contexto de base

Uma das maneiras mais eficazes de fornecer respostas confiáveis é dar ao modelo dados para fundamentar suas respostas (dados de base). Se o seu caso de uso depender de informações confiáveis e atualizadas e não for puramente um cenário criativo, é altamente recomendável fornecer dados de referência. Em geral, quanto mais o material de origem se aproximar da forma final da resposta desejada, menos trabalho o modelo precisa fazer, o que reduz as chances de erro. Aqui está um exemplo em que o sistema recebe um blog que descreve o launch do GPT-4 em Azure OpenAI em Microsoft Foundry Models e solicitado a nomear alguns de seus primeiros clientes.

Práticas recomendadas

  • Seja específico. Deixe o mínimo possível de interpretação. Restrinja o espaço operacional.
  • Seja descritivo. Use analogias.
  • Aprimore-se. Às vezes, será necessário repetir o modelo. Dê instruções antes e depois do conteúdo primário, use uma instrução e uma indicação e assim por diante.
  • A ordem importa. A ordem na qual você apresenta informações para o modelo pode afetar a saída. Se você colocar instruções antes do conteúdo ("resumir o seguinte...") ou depois ("resumir o acima...") pode fazer a diferença na saída. Até mesmo a ordem dos exemplos de poucas cenas pode importar. Essa diferença é conhecida como viés de recência.
  • Dê uma opção de saída ao modelo. Às vezes, pode ser útil dar ao modelo um caminho alternativo se não for possível concluir a tarefa atribuída. Por exemplo, ao fazer uma pergunta sobre um texto, você pode incluir algo como "responder com 'não encontrado' se a resposta não estiver presente". Essa adição pode ajudar o modelo a evitar a geração de respostas falsas.

Eficiência de espaço

Embora o tamanho de entrada aumente a cada nova geração de modelos GPT, você ainda pode encontrar cenários que fornecem mais dados do que o modelo pode manipular. Os modelos gpt dividem palavras em "tokens". Embora palavras multissílabas comuns sejam geralmente um único token, palavras menos comuns são divididas em sílabas. Os tokens às vezes podem ser contraintuitivos, conforme mostrado pelo exemplo a seguir, que demonstra limites de token para diferentes formatos de data. Nesse caso, a ortografia de todo o mês é mais eficiente em termos de espaço do que uma data totalmente numérica.

Dado esse espaço limitado, é importante usá-lo da forma mais eficiente possível.

  • Tabelas – Conforme mostrado nos exemplos da seção anterior, os modelos de GPT podem entender facilmente os dados formatados de tabela. Esse formato pode ser uma maneira eficiente de incluir dados, em vez de preceder cada campo com um nome (como com JSON).
  • Espaço em branco – espaços em branco consecutivos são tratados como tokens separados, o que pode desperdiçar espaço. Espaços anteriores a uma palavra, por outro lado, normalmente são tratados como parte do mesmo token que a palavra. Observe com atenção o uso de espaços em branco e não use pontuação quando um espaço por si só bastar.
