O que é a análise integrada do Power BI?

Neste artigo

Aplica-se a:✅ Power BI análise integrada para seus clientes (dados próprios do aplicativo) e Power BI análise inserida para sua organização (dados do usuário)

As análises incorporadas do Power BI permitem incorporar conteúdo do Power BI, como relatórios, dashboards e blocos, em sites e aplicativos Web executados em navegadores da Web compatíveis. Você pode:

  • Fornecer experiências de dados atraentes para seus usuários finais, permitindo que eles executem ações com base nos insights dos dados de suas soluções.

  • Fornecer relatórios, dashboards e análises excepcionais voltados para o cliente com rapidez e facilidade em seus aplicativos usando e marcando o Power BI como o seu.

Proteger inserção

A inserção segura é a maneira sem código mais simples de inserir um relatório em qualquer portal que aceite uma URL ou iFrame. O visualizador do relatório deve ter a licença adequada do Power BI. O visualizador pode interagir com o relatório, mas não editar, salvar ou fazer alterações nele. A inserção segura está disponível no serviço do Power BI.

Para soluções mais avançadas que oferecem aos usuários mais flexibilidade e controle, use uma das soluções de análise integrada do Power BI descritas neste artigo.

Quais são as soluções de análise integrada do Power BI?

Com a análise integrada do Power BI, você pode integrar recursos analíticos e de BUSINESS Intelligence (BI) diretamente em aplicativos . Isso permite que os usuários finais explorem, analisem e visualizem dados por conta própria e permitem uma tomada de decisão mais rápida e intuitiva sem precisar mudar para ferramentas de BI separadas fora dos aplicativos.

Principais recursos do Self-Service Embedded Analytics:

  • Auto-suficiência do usuário – pode gerar relatórios e analisar dados sem depender totalmente dos analistas de TI/desenvolvimento/dados

    • interface User-Friendly – projetada para usuários não técnicos, dashboards interativos e ferramentas de relatórios intuitivas

    • Personalização – os usuários podem modificar ou criar relatórios personalizados com base em suas necessidades

  • Integração dentro de aplicativos, como CRM, ERP ou aplicativos personalizados e acomodando cenários, como:

    • Acesso a dados quase em tempo real – para os insights atualizados dos dados do aplicativo e de várias outras fontes de dados

    • Habilitar insights acionáveis – o usuário pode conduzir a ação dentro do aplicativo com base nos dados selecionados nos relatórios

  • Recursos de Análise Avançada – incluindo insights orientados por IA, análise preditiva e descoberta automatizada de dados.

A análise integrada do Power BI oferece duas soluções:

  • Inserir para seus clientes

  • Inserir para a organização

Inserir para seus clientes

A solução inserir para seus clientes permite que você crie um aplicativo que usa autenticação no Power BI não interativa. Seus clientes provavelmente são usuários externos e não precisam entrar usando credenciais do Power BI para ver o conteúdo inserido. Normalmente, essa solução é usada por ISVs (fornecedores independentes de software) que estão desenvolvendo aplicativos para terceiros. Para ver um tutorial, veja Inserir o conteúdo do Power BI usando um exemplo de inserção para seu aplicativo de clientes.

Inserir para sua organização

A solução Embed para sua organização permite que você crie um aplicativo que requer a utilização de credenciais do Power BI. Uma vez conectados, os usuários só podem consumir o conteúdo incorporado aos quais têm acesso no serviço do Power BI. Essa solução destina-se a grandes organizações que estão criando um aplicativo para usuários internos. Para ver um tutorial, confira Inserir o conteúdo do Power BI em um aplicativo para a organização.

O que são as capacidades do Power BI?

A capacidade é um conjunto de recursos reservado para seu uso exclusivo. Ela permite publicar dashboards, relatórios e conjuntos de dados para seus usuários sem precisar comprar licenças por usuário. Ela também oferece desempenho confiável e constante para seu conteúdo.
Para os testes de desenvolvimento, você pode usar tokens de avaliação de inserção gratuitos com uma licença Pro. Para fazer uma inserção em um ambiente de produção, você precisa usar uma capacidade.

Importante

Os tokens de avaliação gratuitos são limitados apenas a testes de desenvolvimento. Para produção, uma capacidade deve ser adquirida. Até que uma capacidade seja adquirida, o banner Versão de avaliação gratuita continuará aparecendo na parte superior do relatório inserido.

Há dois tipos de ofertas de análise integrada do Power BI e uma oferta do Microsoft Fabric. Cada oferta inclui um tipo diferente de SKU usado para comprar uma capacidade do Power BI:

  • Power BI Embedded é uma oferta do Azure que inclui SKUs A. O Power BI Embedded está associado à solução inserir para seus clientes.

  • O Power BI Premium é uma oferta do Microsoft Office que inclui SKUs P ou EM.

  • Microsoft Fabric é uma oferta da Azure que inclui SKUs F.

Para obter mais informações sobre as diferenças entre SKUs Embedded e Premium, confira Capacidade e SKUs na análise integrada do Power BI.
